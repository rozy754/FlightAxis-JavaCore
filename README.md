FLIGHT AXIS – Java Core	   

~ Developed a Java-based Airline Management System with a user-friendly GUI. 

~ Key features include passenger profile management, flight booking and cancellation, journey details, and payment tracking.   

~ Implemented efficient event handling and seamless integration with databases for real-time data management. 

~ The project showcases expertise in GUI design, event-driven programming, and database connectivity.

~ Tools Used: Java Swing, AWT, AWT Event and JDBC (Java Database Connectivity)
